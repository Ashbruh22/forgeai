# user
calculator: evaluates an arithmetic expression exactly. Use it for every total, discount, percentage or unit conversion instead of computing in your head.
args: {"expression": "<string>"}. Supports + - * / // % ** parentheses and round(), min(), max(), abs(), sum(), ceil(), floor(), sqrt(). Use plain numbers only, with no currency symbols or thousands separators. Example: {"expression": "round(120 * 14.5 * (1 - 0.08), 2)"}
