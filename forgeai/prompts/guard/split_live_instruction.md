# user
This topic concerns something that changes over time, but the documents are a static snapshot.
One aspect must be the RECORDED version: what a catalogue, list or table in the documents shows
about the item (where it is listed or held, how many are listed, what it is listed as). Another aspect
must be the LIVE value (the current quantity, status or availability) with needs_live_values true.
Phrase the recorded aspect so it clearly says it is what the documents list, not what is current.
